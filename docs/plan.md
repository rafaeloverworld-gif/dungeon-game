# 遊戲計劃 v1.0（已確認 2026-10-20）

> 職業表見 claude.ai project「Website Game」入面嘅 `class-table-draft.md`。

## 1. 一句講晒
手機為主嘅 idle 地城遊戲：角色自動喺 2.5D 地城殺敵，玩家 build 職業、裝備同技能樹，挑戰愈嚟愈難嘅地城。4 個基礎職業可以按次序混合成 16 個覺醒職業。

## 2. 目標同平台
- 興趣 / 練手項目
- 手機 + 電腦，手機為主；**直向**畫面，電腦兩邊留黑邊
- 用 PWA 發佈（GitHub Pages 或 Cloudflare Pages）
- TypeScript + Vite + Three.js（固定斜角鏡頭 + 低多邊形 3D）
- 美術用免費、可商用嘅低多邊形素材包（KayKit / Quaternius / Kenney），用之前先查授權

## 3. 操作
- 自動駕駛 + 隨時接手：預設全自動行同打；掂螢幕即變搖桿，放手幾秒變返自動
- 自動模式效率稍低，玩家親自操控有回報
- 自動普攻；覺醒招牌技可以手動放

## 4. 地城
- 一個地城 = 3 張地圖，最多 10 分鐘（build 愈強愈快）
- 地圖 1、2：殺夠數量 → 小 Boss → 下一張地圖
- 地圖 3：最終 Boss
- 敵人不停 spawn
- 難度：每升一級，敵人血 / 攻 ×1.15；每 5 級新敵人或新能力；每 10 級換主題
- v1 敵人：3 種小兵（近戰追擊、遠程射擊、細隻快速成群）+ 1 小 Boss + 1 最終 Boss

## 5. 掉落同經濟
- 小兵只跌金幣
- 小 Boss：30% 跌**銀箱**（普通 / 稀有為主）
- 最終 Boss：必跌**金箱**（稀有或以上，有機會傳說）
- 地城等級愈高，好裝備機率愈高
- 寶箱撿起後暫存，**通關先入袋**，通關即刻開
- 死亡：保留金幣同經驗，地城唔算過關，寶箱冇晒
- 唔要嘅裝備分解成金幣（稀有度愈高愈多）
- 金幣用途：升級裝備、永久屬性、洗點
- 離線收益：按最高通關地城計，上限 8 小時，只有金幣同經驗，冇寶箱

## 6. 職業
- 3 個基礎職業：戰士、弓手、魔法師
- 第 5 級地城通關後解鎖第二職業，主 + 副 = 覺醒職業（次序有分別，共 9 個）
- 死靈法師留待之後

## 7. 裝備
- 9 個位：主武器、副武器、頭盔、胸甲、腰帶、褲、鞋、戒指、項鍊（戒指同項鍊係 2026-10-21 加）
- 稀有度：普通 / 稀有 / 史詩 / 傳說
- 只有主武器同副武器喺模型上顯示
- 未覺醒：副武器位放輔助裝備（戰士盾、弓手箭筒、魔法師法球）
- 覺醒後：副武器位 = 副職業武器；雙手武器佔兩個位，數值約等於「主 + 副再加一成」

## 8. 技能樹
- 三棵樹：主職業樹、副職業樹、覺醒樹
- 副職業樹同主職業樹完全一樣（全開放，由底向上升）
- 同職業做主副 = 兩棵一樣嘅樹：
  - 數值節點：效果疊加
  - 解鎖節點：第二次點 = 強化版（例如雙倍傷害、範圍更大）。每個技能嘅強化版喺數據入面預先定好
- 每棵基礎樹點滿 25 點，覺醒樹點滿 10 點
- 最高 50 級，每級 1 點，共 50 點（填唔晒，要揀）
- 洗點：第一次免費，之後收費 = 已用點數 × 金幣單價（實際數字試玩再調）
- 次序嘅分別靠：主武器、基礎屬性、覺醒樹

## 9. 屬性同計算
- 9 個屬性：HP、攻擊、防禦、攻速、移速、暴擊率、暴擊傷害、射程、範圍大小
- 計算：所有「+%」先相加，再乘所有「×」
  - 例：100 × (1 + 0.1 + 0.2) × 1.3 = 169

## 10. 多人
- 第一版純單人
- 第二版：即時合作（幾個朋友），朋友做主機（WebRTC 點對點）；配對伺服器放 Bloom.host
- 第一版 code 將遊戲邏輯同畫面分開，預留合作

## 11. 存檔
- 第一版：瀏覽器本地存檔 + 匯出 / 匯入
- 加多人時再上伺服器
