# 開發計劃：第 1 步 + 多人（A 同 B）

（2026-10-22。工作量用「次」計，一次大約係今日咁長嘅一輪工作。全部係估計。）

## 第 1 步：新手教學更新 + 法師加強（大約 1 次）

### 1a. 法師加強
- 問題：機械人測試去到第 20 級，法師要 7.6 小時，其他職業 2.2–4.5 小時。最高通關法師 28，其他 34–39
- 原因估計：HP 110 最低、攻擊間隔 0.9 秒最慢，後期火球爆炸範圍追唔上怪物數量
- 做法：一次只改 1–2 個數，每次都跑 180 場機械人
  - 候選 1：HP 110 → 130
  - 候選 2：攻擊間隔 0.9 → 0.8 秒
  - 候選 3：爆炸範圍 2.1 → 2.4
  - 候選 4：隕石攻速懲罰 ×0.65 → ×0.75
- 合格標準：到第 20 級 3–4.5 小時，最高去到 32–38 級
- 唔可以超過戰士同死靈

### 1b. 新手教學更新
- 修正過時內容：
  - 歡迎畫面寫「第 5 級之後可以覺醒」
  - 技能板提示寫「一共三塊」，而家昇華之後有四塊
  - 要對返最新嘅規則
- 新增一次性提示，喺第一次見到相關畫面時出：
  - 昇華（第三職業）：甚麼時候可以昇華、會退返材料、揀咗唔可以改
  - 攻擊方式揀選（箭種 / 法術 / 死靈主打法）：喺裝備頁第一次見到時出
  - 終極技：最多裝 3 個、Lv 10「極限」效果、觸發型同冷卻型嘅分別、靈晶從邊度嚟
  - 技能盤「一次過解鎖成條路」
  - 通關後「自動再挑戰」
- 新手任務鏈加 2–3 個新任務，例如解鎖第一個終極技、換一次攻擊方式
- 測試：新存檔由頭玩一次（中英文都要），截圖檢查每個提示只出一次

## A. 帳號、雲端存檔、排行榜（大約 2–3 次）

### 運作方式
- 網頁照樣放 GitHub Pages
- 後台用 Supabase（免費版），提供登入、數據庫同即時頻道
- 遊戲照舊可以離線玩，存檔照舊先存喺手機，有網先同步上雲

### 你要做嘅
- 開 Supabase 帳號同 project
- 畀我 project URL 同 anon key（呢兩個放喺網頁入面係正常設計，唔係秘密）
- 決定玩家名點處理（見最尾「要你決定」）

### A1 雲端存檔（1 次）
- 登入：匿名帳號自動開；第一次用網上功能要求玩家起一個玩家 ID；可以之後綁 email（magic link）方便換機
- 數據表 `saves`：用戶 id、存檔 JSON、版本、更新時間
  - Row Level Security：每個人只可以讀寫自己嗰份
- 同步規則：
  - 每次通關同離開主頁時上傳
  - 開遊戲時比較時間：雲端新過手機就問玩家用邊份，唔會靜靜雞覆蓋
- 設定頁加「帳號」區：登入狀態、立即同步、喺另一部機登入

### A2 排行榜（1 次）
- 數據表 `scores`：最高通關、最快去到第 20 級、每日世界 Boss 最高傷害
- 通關時由遊戲提交
- 新頁「排行」：總榜、今日世界 Boss 榜、同職業榜
- 已知風險：戰鬥喺手機度計，識改存檔就可以作弊
  - 限喺班學生入面接受得
  - 如果之後要開放俾陌生人，就要伺服器驗證，工作量會加倍

### A3 睇其他人嘅 build（0.5 次）
- 排行榜撳入去睇：職業組合、裝備、技能盤、終極技（唯讀）

## B. 即時合作（大約 8–12 次）

### 運作方式
- 2 人一隊，同一個地城一齊打
- 其中一部手機做主機，計成個戰鬥：怪物、傷害、掉寶
- 其他手機只傳「搖桿方向 / 招牌技」上去，每秒收 15 次畫面狀態，再補幀令動作順滑
- 連線用 WebRTC，手機直接連手機；Supabase 即時頻道負責配對（房間碼）
- 學校 Wi-Fi 同手機網絡有時會擋手機直連，要一個 TURN 中轉伺服器。有免費額度嘅服務，但要實測學校網絡先知用唔用到

### 每個玩家保留自己嘅嘢
- 自己嘅職業、裝備、技能盤、終極技、亡靈
- 獎勵：每個人自己部機按戰鬥結果攞自己嘅掉寶同材料，唔使分

### 遊戲規則要改
- 敵人 HP 2 人時 ×1.7（之後再調）
- 敵人會揀最近或者仇恨最高嘅玩家打
- 升級唔再暫停：全隊共用經驗，每人有 10 秒揀卡，超時自動揀
- 玩家死咗：倒地 10 秒，隊友企埋身邊可以救起；全隊倒晒先算失敗
- 斷線嘅玩家由自動駕駛接手，返嚟可以接返控制

### 開發階段
- **B0 引擎改做多玩家（3–4 次）**：最大嘅一步，同網絡無關
  - `sim.player` 改做 `players[]`，影響大約 50 幾處：攻擊、技能、終極技、亡靈、自動駕駛、升級
  - 驗收：同一部機跑兩個自動駕駛玩家；單人模式機械人結果同改之前一樣，證明冇整壞單人
- **B1 房間同配對（1 次）**
  - 開房得到 4 位房間碼，其他人輸入入房
  - 大廳顯示各人職業，主機揀地城等級，然後開始
- **B2 網絡同步（2–3 次）**
  - 輸入上傳、狀態下傳（壓縮位置數據，每秒大約 20 KB 以內）
  - 客戶端補幀
  - 測試延遲同掉包
- **B3 合作規則（1–2 次）**：人數加成、揀卡唔暫停、倒地同救起、獎勵
- **B4 斷線處理（1–2 次）**
  - 第一版：主機斷線 = 結束今局，按已殺數量畀獎勵
  - 之後先考慮換主機
- 實機測試：兩部 iPhone 加一部 Android，喺學校 Wi-Fi 同 4G 都要試

### 已知風險
- iPhone Safari 一轉 app 或者鎖機就會斷線，冇得避免，只可以做好重連
- 主機部手機要計全部嘢，舊手機做主機可能會卡，可以限制怪物上限
- 戰鬥喺主機計，主機可以作弊；學生之間玩可以接受
